# 声长 · Speak & Grow

适合手机使用的个人美式口语训练工具。无依赖、无构建步骤、无账号，无需配置 AI 密钥。页面与课程可部署到 GitHub Pages。

## 包含什么

- 24–36 个月能力路线；前 12 周共 60 次训练。
- 30 / 45 / 60 分钟日程，听懂、分句模仿、影子跟读、独立表达、复盘五步循环。
- 12 份原创对话与每周不同的练习重点、迁移任务、追问和讨论题。
- 本机音频导入、对应文本、速度控制、A–B 循环；设备美式英语朗读作为试练补充。
- 麦克风录音、回放、下载及本机保存。
- 专注计时（切到后台自动暂停）、笔记、自评、陪练反馈、练习历史。
- 陪练任务卡：复制到聊天，练完把反馈带回网页；没有自动同步或内嵌 AI。
- 完整 JSON 备份与恢复，包括音频。首次打开后缓存核心页面，断网仍可使用；设备朗读的离线能力由手机决定。

月份只是规划窗口，不是达标承诺。自评不等于考试分数。第五天的 AI 陪练需要你主动到外部聊天完成；未完成时请不要勾选。

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库，把本目录的 `index.html`、`styles.css`、`app.js`、`curriculum.js`、`sw.js`、`manifest.webmanifest`、`icon.svg` 和 `.nojekyll` 放到仓库根目录。也可直接上传本目录中的全部网站文件。
2. 进入仓库 **Settings → Pages**，选择 **Deploy from a branch**，选择存放文件的分支与 **/(root)**，保存。
3. 等待部署完成，访问 GitHub 给出的 HTTPS 地址。项目子路径可用，所有资源均采用相对地址。
4. 在手机浏览器中打开，允许麦克风。需要时通过浏览器菜单“添加到主屏幕”。

本版本交付本地文件，不会自行创建仓库或发布。无需将录音、学习备份或个人音频上传到公开仓库；它们默认仅保存在手机浏览器中。

## 本地预览

在此目录运行 `python -m http.server 4173 --bind 127.0.0.1`，然后在同一台电脑打开 `http://127.0.0.1:4173`。不要双击 HTML 作为正式使用方式；手机上的录音需要 HTTPS。电脑回环地址不能直接作为手机访问地址，请部署到 Pages 后在手机检查。

## 使用建议

1. 先做第一周第一天，留一段自我介绍录音。
2. 在跟读练习室选择周次，导入自己的短音频，一行一句粘贴对应英文文本。未导入时使用内置原创文本；内置文本与导入的原声不会自动对齐。
3. 真人原声导入后，可用起止秒数设置 A–B 循环。设备朗读并非真人口音范本；如果手机没有 `en-US` 音色，会提示导入原声。
4. 先听懂，再分句模仿、同步跟读，最后用自己的内容说。按实际完成情况勾选，计时不会自动打卡。
5. 周五复制陪练任务卡到聊天。发音评估只有在陪练实际能够分析录音时才进行。
6. 每周导出完整备份。浏览器清理数据、换手机或换域名前尤其需要备份。导入会替换本机记录，确认前先备份。

## 数据与设备限制

- 学习记录保存在 localStorage；音频保存在 IndexedDB。域名、浏览器或设备改变后不会自动迁移。
- 浏览器存储可能因空间不足或清理而丢失。存储不可用时页面提示，仍可下载录音或导出当前会话数据。
- 单个导入音频上限 30 MB；建议总音频不超过 90 MB。完整备份导入上限 150 MB（解码后音频上限 100 MB）。单段录音最多 10 分钟。
- 切换页面或切到后台会停止并尽量保存正在进行的录音；直接强制关闭浏览器可能来不及写入。结束录音后请检查是否能回放。
- 不同手机的音频格式、录音权限、合成音色不同，需要在实际设备上验证。推荐在 Safari 或 Chrome 中打开正式 HTTPS 地址。
- PWA 图标使用 SVG；部分 iPhone 主屏幕图标可能采用网页截图。网页功能不依赖安装。
- 更新网站内容后在线重新打开；缓存采用在线优先策略。练习记录与静态缓存相互独立。

## 课程与维护

课程在 `curriculum.js` 中。之后阶段采用能力目标，不预先伪造未来三年的细课；在第 4、8、12 周检查后续需要，再添加课程。

网站没有外部字体、跟踪脚本或第三方音频请求。设备朗读是否调用系统在线音色由操作系统决定。
